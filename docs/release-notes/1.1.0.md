# SelfFire 1.1 「화롯불」 출시노트

> **홈 화면에서도 꺼지지 않는 불씨** 🔥
> 화롯불은 집 안에서 불씨를 지켜 주던 불입니다. 이번 업데이트는 앱을 열지 않아도 매일의 다짐이 홈 화면에 머물도록 하는 데 집중했습니다.

---

## 출시명

**추천: SelfFire 1.1 「화롯불」 (Hearth)**

- 이번 릴리스의 핵심은 **홈 위젯**입니다. 불씨를 집(홈 화면)으로 옮겨 놓는다는 뜻이 「화롯불」 한 단어에 담깁니다.
- 앱의 세계관(불씨 → 점화 → 스트릭)과 이어지고, 다음 버전 이름도 불의 단계로 이어 갈 수 있습니다.
  예: 1.0 「불씨」 → 1.1 「화롯불」 → 1.2 「모닥불」 → 2.0 「횃불」

**대안**

| 이름 | 느낌 | 어울리는 경우 |
| --- | --- | --- |
| 「새 옷을 입은 불씨」 | 리뉴얼 강조 | 디자인 변경을 가장 앞에 내세울 때 |
| 「오늘의 불씨」 | 일상, 루틴 | '하루 한 문장' 경험을 강조할 때 |
| Spark (스파크) | 짧고 가벼운 영문 이름 | 해외 스토어까지 같은 이름을 쓸 때 |

```
🔥 SelfFire 1.1 「화롯불」 — 홈 화면에서도 꺼지지 않는 불씨

이제 앱을 열지 않아도 동기부여가 함께해요.

• 홈 위젯: 오늘의 명언과 불씨(스트릭) 상태를 홈 화면에서 바로 확인하세요
• 오늘의 명언: 하루 동안 같은 명언을 곱씹을 수 있고, 알림으로 받는 명언과도 똑같아요
• 카드 배경: 노을·바다·숲·밤하늘·오로라 등 8가지 배경으로 나만의 카드를 꾸며 보세요
• 카테고리: 성공·노력·용기·행복·사랑·인생·지혜 등 원하는 주제만 골라 보세요
• 새 디자인: 홈, 설정, 사이드바까지 전부 새로 다듬었어요

그리고
• 긴 명언도 카드 안에 깔끔하게 들어가요
• 태블릿·폴더블에서 가로 화면을 지원해요
• 앱이 더 가볍고 빨라졌어요

오늘도 불씨를 지펴 보세요 🔥
```

앱을 열지 않아도 오늘의 명언과 불씨 상태가 홈 화면에 보여요. 오늘 불씨를 지폈는지, 며칠째 이어 가고 있는지 한눈에 확인하세요.

☀️ 하루 한 문장, 오늘의 명언
오늘의 명언은 하루 동안 바뀌지 않아요. 아침에 알림으로 받은 문장을 앱과 위젯에서도 그대로 다시 만날 수 있어요.

🖼 카드 배경
노을, 불씨, 바다, 숲, 밤하늘, 오로라, 새벽, 종이까지 8가지 배경 중에서 골라 명언 카드를 꾸며 보세요.

🗂 카테고리
성공·도전, 노력·끈기, 용기·희망, 행복, 사랑, 우정·관계, 인생, 지혜·배움, 성경. 지금 필요한 주제의 명언만 골라 볼 수 있어요.

✨ 처음부터 다시 그린 디자인
홈, 바텀 시트, 사이드바, 설정 화면까지 전부 새로 다듬었어요. 테마와 글꼴도 더 쉽게 고를 수 있어요.

━━━━━━━━━━━━━━━━
더 좋아진 점
━━━━━━━━━━━━━━━━

• '새 명언으로' 버튼: 이미 본 명언이 나오면 버튼 하나로 새 문장을 볼 수 있어요
• 긴 명언은 글자 크기가 자동으로 맞춰져 카드 밖으로 넘치지 않아요
• 태블릿과 폴더블에서 가로 화면을 지원해요
• 앱 용량이 줄고 실행이 빨라졌어요

━━━━━━━━━━━━━━━━
고친 점
━━━━━━━━━━━━━━━━

• 큰 글꼴을 쓸 때 화면이 깨지거나 스와이프가 안 되던 문제
• 화면을 돌리면 하단 배너가 어긋나던 문제

SelfFire를 써 주셔서 고맙습니다. 의견은 언제든 리뷰로 남겨 주세요. 꼼꼼히 읽고 다음 불씨에 담을게요 🔥

| **Calm · Headspace** | 기능 목록 앞에 한 문장 비전("홈 화면에서도 꺼지지 않는 불씨")을 두어 감성 앱의 톤을 유지 |
